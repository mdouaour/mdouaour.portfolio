## 📁 Project Structure

```
src/
├── components/
│   ├── Navbar.jsx      # Sticky responsive navigation
│   ├── Hero.jsx        # Full-screen landing with social links
│   ├── About.jsx       # Bio, education, and quick facts
│   ├── Skills.jsx      # Grouped skill badges
│   ├── Projects.jsx    # Project cards (GitHub + live links)
│   ├── Contact.jsx     # Contact form + quick links
│   └── Footer.jsx      # Footer with links
├── App.jsx             # Root layout
├── index.css           # Tailwind base styles
└── main.jsx            # React entry point
```

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```

---

## 📦 Deployment (Vercel)

1. Push this repo to GitHub
2. Import it on [vercel.com](https://vercel.com)
3. Vercel auto-detects Vite – click **Deploy**

No extra configuration needed.
